# 🐾 Pawmates

Platform komunitas pencinta anjing di Indonesia untuk berbagi cerita, informasi perawatan, event, dan adopsi.

---

## 🚀 Tech Stack
* **Frontend:** Next.js, TypeScript, Tailwind CSS
* **Backend:** Express.js, Node.js
* **Database:** MySQL
